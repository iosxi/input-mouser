# input-mouser

1 組のキーボードとマウスで、LAN でつながった複数の Windows PC を操作する常駐ソフトです。
マウスを画面の端まで動かすと、その向きに置いた PC へカーソルが移り、キーボードもその PC に効きます。
Input Director と同じ役目を、今の Windows 向けに作り直しました。

- **インストール不要。** `input-mouser.exe` を好きな場所に置いて起動するだけ。どの PC にも同じ exe を置きます。
- **レジストリを使わない。** 設定は exe と同じ場所の `input-mouser.ini`（UTF-8 のテキスト）だけ。
  「Windows の起動時に開始」もスタートアップ フォルダのショートカットで行います。
- **軽い。** exe 1 個（約 250KB、ほかの DLL やランタイムは不要）。何もつながっていない間は
  通信のスレッドも眠ったままで、見回りのために起きることもありません。
- **画面は Windows 11 の標準的な見た目。** ライト／ダークはシステムに合わせます。すべて日本語。

## Input Director との違い

| | Input Director | input-mouser |
|---|---|---|
| 導入 | インストーラー、サービスの登録 | exe を置くだけ |
| 設定の置き場所 | レジストリ | exe の隣の ini |
| 画面の並べ方 | マスターの上下左右の欄に PC 名を入れる | Windows の「ディスプレイの配置」と同じく、PC のタイルをドラッグして並べる。斜めや 2 段先にも置ける |
| 相手の探し方 | 名前か IP を手で入れる | 同じネットワークで受け付けている PC を自動で一覧に出す |
| 暗号化 | AES（任意） | 常に AES-256-GCM。パスワードは保存せず、PBKDF2 で作った鍵だけを ini に書く |
| 役割 | マスター／スレーブを切り替える | 1 台が両方を兼ねられる（相手を登録すればマスター、受け付けを入れればスレーブ） |
| 画面 | 昔の UI | Windows 11 の標準的な見た目、ダーク対応 |

## 使い方

1. 操作したい PC すべてに `input-mouser.exe` を置いて起動します。最初だけ設定画面が開き、以後は通知領域（タスクトレイ）に常駐します。
   - 初めて起動したとき、Windows ファイアウォールの確認が出ます。**プライベート ネットワークで許可**してください
     （ほかの PC からの接続と、PC の探索を受けるため）。
2. どの PC でも「パスワード」の「変更」から、**同じパスワード**を設定します。
3. キーボードとマウスがつながっている PC（マスター）で「PC を追加」を押します。
   同じネットワークで input-mouser が動いている PC が一覧に出るので、選んで「OK」。
   見つからないときは PC の名前か IP アドレスを入れます。
4. 「画面の配置」で、相手の PC のタイルを実際に置いてある向きへドラッグします。
   タイルの丸い印が緑（接続済み）になれば使えます。
5. マウスを画面の端まで動かすと、その向きの PC に移ります。戻るときは反対の端へ。

トレイのアイコンをクリックすると設定画面、右クリックで切り替え先・切り替えの固定・一時停止・終了。
相手を操作している間は、トレイのアイコンの右の画面が水色になります。

### 切り替えの設定

| 項目 | 意味 |
|---|---|
| 端で押し続ける時間 | 0 なら端に触れた瞬間に移る。たとえば 300 にすると、端へ 0.3 秒押し続けたときだけ移る（うっかり移るのを防ぐ） |
| 角の無効範囲 | 画面の角から指定のピクセル以内では移らない（角のボタンを押しに行ったときに移らないように） |
| マウスのボタンを押している間は切り替えない | ドラッグ中に端へ行っても移らない |
| クリップボードを共有する | 移るときに、文字と画像をコピーした内容ごと渡す（ファイルは渡さない） |
| このPC に戻る | どこを操作していても、このホットキーで手元の PC に戻る（既定 Ctrl+Alt+Home） |
| 切り替えを固定 | 押すたびに、端での切り替えを止める／再開する |

相手の PC ごとにも「この PC へ直接切り替える」ホットキーを付けられます。
ホットキーの欄は、欄を選んでそのままキーを押すと登録され、Delete で消せます。

### 接続と安全

- 通信は 1 本の TCP（既定のポート 31860）。最初にお互いのパスワードを確かめ合い（パスワードそのものは流さない）、
  以後は AES-256-GCM で暗号化します。番号付きで暗号化するので、通信の差し込みや再送は通りません。
- パスワードが違う PC からの接続は断ります。設定画面のタイルに「パスワードが違います」と出ます。
- 探索は UDP のブロードキャスト（同じポート番号）で、受け付けている PC の名前とポートだけを返します。

## できないこと（Windows の制限）

- **相手の PC のロック画面・Ctrl+Alt+Del・UAC の確認画面は操作できません。**
  これらは「安全なデスクトップ」で、普通のアプリからは入力を送れないためです
  （Input Director はサービスを登録して対応していますが、インストール不要の方針と両立しません）。
- **相手の PC で「管理者として実行」したウィンドウには、入力が届きません**（UIPI）。
  相手の PC で input-mouser を管理者として起動すれば届くはずですが、確かめていません。
- 手元の PC で Ctrl+Alt+Del を押したり画面をロックしたりすると、手元の操作に戻ります
  （相手の PC で押したままになったキーは離させます）。
- クリップボードでファイルは渡せません（文字と画像のみ。既定で 32MB まで）。

## 設定ファイル（input-mouser.ini）

設定画面で変えると書き直されます。手で書き換えるときは input-mouser を終了してから。

```ini
[general]
accept=1                  ; ほかの PC からの操作を受け付ける
port=31860
key=…                     ; パスワードから作った鍵(64 桁の 16 進)
edge_delay=0              ; 端で押し続ける時間(ミリ秒)
corner=0                  ; 角の無効範囲(ピクセル)
no_drag_switch=1
clipboard=1
clipboard_max_mb=32       ; 送るクリップボードの上限
hotkey_home=Ctrl+Alt+Home
hotkey_lock=
osd=1                     ; 切り替えたとき画面の下に小さく知らせる
theme=                    ; light / dark で固定(空ならシステムに合わせる)

[peer]                    ; 操作する相手。何台でも(8 台まで)
host=OFFICE-PC
port=31860
x=1                       ; この PC から見た位置。右が +、下が +
y=0
hotkey=Ctrl+Alt+F2
```

exe が書き込めない場所（Program Files など）にあるときは、`%APPDATA%\input-mouser\input-mouser.ini` を使います。

## コマンドライン

| 引数 | 意味 |
|---|---|
| （なし） | 常駐を始める。すでに動いていれば設定画面を出す |
| `-settings` | 常駐を始めて設定画面を出す |
| `-switch <n>` | 動いている input-mouser に切り替えさせる（`0` / `home` = この PC、`1`〜 = 登録した順の相手） |
| `-exit` | 動いている input-mouser を終わらせる |
| `-ini <path>` | 設定ファイルを指定する |
| `-log` | 動作を `<設定ファイル名>.log` に書く |

## 作り方

MinGW-w64（gcc・windres）で `build.cmd`。アイコンは `python tools/make-icon.py`（Pillow が要る）。
自動検証は `powershell -File tools\test.ps1`（1 台の PC で送り手と受け手を並べて動かす）。
